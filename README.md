# Vintage-DGLab

Vintage Story 的客户端郊狼联动模组。**在游戏内完成扫码、血量规则调节、A/B 通道设置、测试与停止**，无需外部 GUI。面板使用游戏原生控件。

当前发布版为 **1.3.1**，使用同一份安装包支持 **Vintage Story 1.22.3～1.22.7**，需要游戏自带的 .NET 10 环境。服务器无需安装模组。

| 分支 | 用途 |
|---|---|
| `main` | 通用包维护，以 1.22.3 真实游戏 API 编译 |
| `support/vs-1.22.3` | 保留 1.3.0 的 1.22.3 构建历史 |
| `feature/vs-1.22.7-gui` | 保留 1.3.0 的 1.22.7 适配历史 |
| `V1.2.0` 标签 | 原 MIT 发布基线 |

下载 **`Vintage-DGLab-1.3.1-vs1.22.3-1.22.7.zip`** 即可，不再按补丁版本分包。最低依赖为 1.22.3；当前声明的支持范围到 1.22.7。1.22.3 已完成 GUI 与真实设备测试，同一份 1.22.3 原包已在 1.22.7 加载进入世界；1.22.4～1.22.6 按兼容范围支持，未逐版实测。详细记录见 [VALIDATION.md](VALIDATION.md)。

## 安装与打开面板

1. 退出游戏，将通用模组 ZIP 放入自己的 `VintagestoryData/Mods`，ZIP 不需要解压。先移走旧版同名模组，避免重复加载。
2. 启动游戏并进入世界。
3. 按 **Ctrl + Alt + G**，或在客户端聊天输入 **`.dglab`** 并回车。
4. 在“手机连接”页选择连接方式，点击 **“生成连接二维码”**，用 DG-LAB APP 扫码。二维码生成前会显示操作提示；可放大、复制链接。
5. 在手机连接郊狼 3.0，设置通道上限。面板显示设备就绪、A/B 上限后，默认自动启用血量联动。连接本身不产生反馈。

模组读取的是本机玩家的血量，不需要放置方块，也不会追踪附近其他玩家。卸载时删除本模组 ZIP；配置文件可按需保留或移除。

## 连接方式

- **DG-LAB 4**：默认官方中继 `wss://trex.dungeon-lab.cn/v4`，可修改。`wss` 是经过 TLS 加密的 WebSocket，二维码使用官方 V4 格式。
- **兼容扫码**：模组在所选本机 IPv4 和端口监听（默认 `8877`），手机与电脑需能在局域网互通。请选择真实局域网网卡地址；代理虚拟网卡地址通常不适合手机直连。

每次重新建立连接都会生成新会话，旧二维码失效。连接多个郊狼时，在“通道与波形”页选择一个设备；一次只控制该设备。

## 实际强度怎么算

**实际目标强度 = 手机对应通道上限 × 当前信号比例 × 该通道输出比例，向下取整。**

例如手机上限 A=100、B=60，通道比例均为 100% 时，“测试 20%”输出 A=20、B=12。若把 B 通道比例改为 50%，同一测试的 B 目标值为 6。

A/B 分别设置启用开关和输出比例，波形与反馈时长共用。上限、静音和舒适限制由手机继续管理；0 上限保持 0，未知上限不会被猜成 100。模组会下发实际强度指令，但不会修改手机的强度上限或解除静音。

V4 上限读取 `slotState.channelA/channelB.intensityMax`，当前强度读取 `props.intensityA/B`。两个字段的含义不同。

## 血量规则与手动测试

- 受伤增加 0～15 的信号值；连续受伤时增加额外系数。
- 回血按恢复量降低信号，重置连续受伤阶数；血量不变时保持信号。
- 基础系数、连续受伤系数、回血系数、单次变化上限均可调。这里的“阶数”按采样到的血量下降计算，不等同于逐个命中的游戏伤害事件。
- 死亡只触发一次反馈，强度比例 0～100%、时长 0.1～10 秒可调；结束归零。复活重新建立血量基线。
- **“测试 20%”** 和 **“测试死亡”** 不要求启用血量联动；前者固定测试 20% / 1 秒，后者使用所设死亡参数。测试会暂时关闭血量联动，结束归零；继续游玩时点击“启用联动”。
- **“停止输出”** 同时停用联动、取消测试并清理两路任务。暂停、退出世界和断线会停止游戏反馈；游戏暂停不会取消独立手动测试的限时清理。重新连接不补播旧反馈。

默认波形为“气泡节奏”，另有“平稳”“呼吸”，均为本项目数学生成的预设。

## 命令与配置

| 命令 | 作用 |
|---|---|
| `.dglab` / `.dglab-qr` / `.dglab-status` | 打开原生面板 |
| `.dglab-connect` / `.dglab-disconnect` | 建立或断开当前配置的手机链路 |
| `.dglab-track` | 启用血量联动 |
| `.dglab-untrack` / `.dglab-stop` | 停止追踪并清零 |
| `.dglab-copy` | 复制当前配对链接 |

参数保存在当前游戏数据目录的 `ModConfig/vintagedglab.json`。端口通过 GUI 修改，保存后重新生成二维码生效；旧 `.dglab-port` 命令不再使用。改变连接方式、网卡或中继地址后也应重新生成二维码。

“设备或通道上限未就绪”的旧问题已修正。新版会区分手机未配对、蓝牙未连接、未选择设备、缺失具体通道上限；先查看面板顶部状态。
